📘 User Manual - EMVELOPE Data Creation

🚀 Quick Start Guide

Welcome! This tool helps you generate EMC test reports efficiently. Follow these simple steps:

Step 1: Select Test Item

  • Click on items in Level 1 (e.g., Conducted Emission, Radiated Emission)
  • Select corresponding items in Level 2, 3, 4 as required
  • Click Confirm button to save your selection

Step 2: Fill in Specification

  • Enter customer name, specification version, date, etc.
  • These fields help identify the test standard

Step 3: Complete General Information

  • Fill in test environment (temperature, humidity)
  • Measurement setup and harness length
  • ★ Yellow highlighted fields are mandatory

Step 4: Configure Parameters

  • Click Setting Parameter button
  • A right-side panel will open with parameter tables
  • Fill in required parameters (marked with ★)
  • Click Confirm to save

Step 5: Export Report

  • Click Export2Excel to generate Excel file
  • File name will be auto-generated based on test item

📖 Detailed Feature Guide

1. Test Item Selection

Color Coding:

  • Green - Available test items
  • Red - Important items requiring attention
  • Gray - Unavailable items
  • White - Sub-level items
💡 Tip: Selected items will show a blue border. Make sure to click Confirm to save your selection.

2. Template & Customer Selection

Use the dropdown menus in the top-right corner:

  • Select Template: Load pre-configured test templates
  • Select Customer: Auto-fill customer information

3. Parameter Configuration Panel

Two types of parameter tables:

  • General Parameters: Common test settings (scan method, measurement setup, etc.)
  • Limit Settings: Test level and limit values

For CTI (Transient Coupled Immunity) tests:

  • Left side shows waveform reference image
  • Right side shows waveform parameters table
  • Fields marked with ★ are mandatory

4. Table Operations

  • Copy button: Duplicate current row with same values
  • Delete button: Remove current row (at least 1 row must remain)
  • + Add Rows button: Add new empty row
⚠️ Warning: For CTI tests, all mandatory parameters (★) must be filled before saving!

📊 Import & Export

Export to Excel

  1. Complete all required fields
  2. Click Export2Excel button
  3. Generated file contains:
    • General Information sheet: Test item, specification, general info
    • SettingPar sheet: General parameters (if applicable)
    • LimitLevel sheet: Limit settings

Import from Excel

  1. Click Import Excel button
  2. Select previously exported Excel file
  3. System will auto-fill all fields and parameters
💡 Best Practice: Export your work regularly to save progress and create backups.

🛠️ Troubleshooting

Common Issues & Solutions

Q: Config loading failed on startup?

A: Make sure:

  • Config.json file is in the same folder as HTML file
  • Open HTML via HTTP server (not by double-clicking)
  • Check browser console (F12) for detailed error messages

Q: Parameter panel doesn't show?

A: Ensure you have:

  • Selected and confirmed test item first
  • Chosen appropriate Level 2 and Level 3 items

Q: Can't save parameters?

A: Check if:

  • All mandatory fields (★) are filled
  • Values are in correct format (numbers, selections, etc.)

Q: Waveform image not displaying?

A: Verify:

  • Image path in Config.json is correct
  • Image file exists in specified location
  • File format is supported (PNG, JPG, SVG)
⚠️ Data Loss Prevention: Always click Confirm in parameter panel and test selection to save your work!

✨ Tips & Tricks

  • Quick Clear: Use Clear All to reset entire form
  • Batch Entry: Use Copy button to quickly duplicate similar rows
  • Visual Feedback: Newly copied rows briefly highlight in green
  • Auto-save: Parameter summary shows in main form after saving
  • Responsive Layout: Right panel automatically adjusts width
